# Prima celula: test manual

Operatorul a raportat executarea testului manual de ridicare si reasezare in
celula sursa 2,2. Pe Pi sunt salvate pozitii approach/contact distincte si o
pozitie de gripper inchis. Configuratia a fost recitita dupa test.

Acesta este un test executat manual din meniul de calibrare. Nu valideaza
automat tranzitul spre celula, un transfer spre destinatie sau o proba autonoma.
Nu se presupune ca numai S2 difera intre toate versiunile calibrarii: exista
si diferente mici in alte articulatii. Unghiurile curente sunt in config pe Pi;
nu se refolosesc valorile numerice vechi din conversatie dupa o recalibrare.

Urmeaza calibrarea approach/contact la destinatie 2,2, apoi verificarea
traseelor dintre statii si transit, cu clestele gol, inainte de primul transfer.
Recuperarea automata ramane dezactivata.
